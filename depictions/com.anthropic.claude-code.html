Claude Code

v2.1.19-2

Run Claude Code natively on your jailbroken iPhone, CLI-only. AI-powered coding assistant by Anthropic.

Features

  • Full Claude Code CLI functionality
  • Node.js 18.20.4 optimized for iOS
  • Login handled entirely by the official CLI (no custom OAuth server)
  • Uses the system ripgrep package for code search
  • Fixed initial-launch hang on iOS terminal apps

Usage

Start Claude Code:

claude

First run prompts you to log in via /login, or run claude setup-token for a headless SSH-only login.

Single query:

claude -p "your prompt here"

Requirements

iOS Version15.0+
JailbreakDopamine, palera1n, etc.
Storage~140MB
Dependencieszsh, ldid, ripgrep
Note: You need a Claude API key or Claude Max/Pro subscription to use this app. There is no home-screen app anymore - this is a terminal-only package.
