Claude Code

v2.1.19

Run Claude Code natively on your jailbroken iPhone. AI-powered coding assistant by Anthropic.

Features

  • Full Claude Code CLI functionality
  • Node.js 18.20.4 optimized for iOS
  • API key and OAuth authentication
  • Home screen app for quick access
  • Works with NewTerm terminal

Usage

Authenticate:

claude-auth

Start Claude Code:

claude

Single query:

claude -p "your prompt here"

Requirements

iOS Version15.0+
JailbreakDopamine, palera1n, etc.
Storage~150MB
Dependencieszsh, ldid
Note: You need a Claude API key or Claude Max/Pro subscription to use this app.
